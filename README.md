## How it started

GS Multi Tool is the evolution of **GS USB Runner**.

What started as a software-based HID scripting project slowly grew into something much bigger. One tool became several. A simple USB-focused utility evolved into a collection of cybersecurity learning tools, privacy utilities, intelligence resources, emergency-preparedness guides, and custom applications.

Then GitHub suspended my account. I could have stayed frustrated about it, but I decided to use that setback as motivation.

**Instead of being bitter, I chose to become better.**

I took everything I learned from GS USB Runner and rebuilt the experience into what you see today: **GhostStrats Multi Tool**, a dedicated Windows desktop application.

This version is designed to be more organized, more polished, and easier to install and maintain. It has a real Windows installer, a desktop shortcut, a Start Menu entry, an uninstaller, a unified dashboard, and dedicated storage for application data.

Moving away from running the entire suite on a flash drive has also made everyday use smoother on many computers.

The goal has not changed: **make useful tools available to the community for free.**

Whether you are learning scripting, studying defensive security, working with your own network data, planning for emergencies, or exploring privacy technology, I hope something here helps you learn or build.

A Linux edition of the **full Multi Tool** is something I would like to work toward. For now, the main application is **Windows-only**, although **GS Local Chat** has a separate Linux Mint version that can communicate with Windows over a local network.

This project will continue to grow with community feedback. Thanks to everyone who has followed its development, tested builds, reported bugs, and shared ideas.
